When one class-group (e.g. "old" classes in class-incremental fine-tuning) underperforms, check per-class counts and confusions BEFORE trying reweighting: in our AST 29-class case the entire old-class gap came from 3 ultra-rare classes (n=3,3,7) at 0% accuracy with systematic confusions to acoustically similar classes. Oversampling old classes x1.5 (-0.007 CV), encoder LR 5e-6 (-0.003), and label smoothing 0.1 (-0.005) all HURT; only +1 epoch helped (+0.002). Rare-class fixes need targeted remedies (ensembling, confusion-aware post-processing, per-class thresholding), not group-level loss/sampler tweaks. Also: on a 12GB local GPU an AST-base run used <1GB, so 2-3 four-fold experiments run concurrently with near-zero mutual slowdown — parallelize sweeps after checking nvidia-smi.
