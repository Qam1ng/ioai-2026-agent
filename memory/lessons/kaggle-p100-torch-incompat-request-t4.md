Kaggle's current PyTorch image (torch built for sm_70+) CANNOT run on Tesla P100 (sm_60): first CUDA op fails with "no kernel image is available for execution on the device". If kernel-metadata.json only sets enable_gpu=true, Kaggle may assign a P100 and the run errors out AFTER burning quota. Fixes: (1) set "machine_shape": "NvidiaTeslaT4" in kernel-metadata.json; (2) defensively, at runtime run a tiny conv2d on cuda inside try/except and fall back to CPU if it throws, so the kernel still produces a submission. Also: transformers 5.x moved AST encoder layers from ast.encoder.layer to ast.layers — write accessor that handles both.
