Kaggle GPU kernels: recent torch builds lack sm_60 kernels, so P100 fails at first CUDA op ("no kernel image"). Always set machine_shape NvidiaTeslaT4 and add a startup sanity check (tiny F.conv2d on cuda in try/except, fall back to CPU) so the kernel still produces output. For audio classification with a frozen AST encoder: caching window embeddings once, then blending a warm-started linear head (on checkpoint-LayerNorm CLS pooled feats) with a small MLP on [pool||mean] concat (probs 0.3 lin + 0.7 mlp) beat both alone and beat partial fine-tuning on the public LB (0.807 vs 0.799) despite fine-tuning training end-to-end; cosine prototypes were the weakest head. CV-to-LB gap ~0.10 was consistent across approaches, so local CV ranking transferred.
