When a task ships a pretrained HF checkpoint but no evaluation page, the official metric is often recoverable from the checkpoint itself: training_args.bin pickles metric_for_best_model (extract with pickletools/regex over the zip's data.pkl if torch.load fails on missing deps like accelerate), and config.json's problem_type + the sample submission's dtype (hard labels vs floats) triangulate the rest. Hard integer labels + single_label_classification + metric_for_best_model=accuracy => accuracy.
