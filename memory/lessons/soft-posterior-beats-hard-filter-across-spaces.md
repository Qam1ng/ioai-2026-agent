当模型要在「可见空间」上推理、却在「不可见的另一个空间」上被评分时（例：公开 embedding vs 私有 embedding），任何硬性消除都是最大失分点：约束在评分空间只是概率成立，一旦公私不一致就永久删掉真答案且无法恢复。改成软似然累积后验（logw += log_sigmoid(BETA*margin)），让输掉一次比较的候选靠其他比较存活。本题该改动把 starter 从 92.58 提到 96.87。

配套的验证方法比模型本身更重要：本地干净判官会奖励硬过滤（starter 自评 92.58 看起来很好），必须自建扰动判官（emb + sigma/sqrt(d)*N(0,1) 再归一化）在 sigma=0/0.6/1.0/1.5 上一起看，只接受全线不劣的改动。本题有两个旋钮只涨干净分却崩高噪分（TOPK 48→16：96.87→97.38 但 sigma1.0 68.72→59.30），只看干净分必选错。

校准的教训（代价最大的一条）：只有 1 个「本地→榜单」数据点时不要下方向性结论。我据 1 点断言 folds 与榜分反向并发了 urgent，第 2 点出来后发现残差近似恒定（-51.20 / -50.87），二者其实同向约 0.85:1，只好自我更正。做局部-全局差异的判断至少要 2 点，且注意残差恒定意味着「最大化本地分」仍然正确。
